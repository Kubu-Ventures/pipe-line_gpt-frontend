# Security Policy

Please report vulnerabilities **privately**, never in public issues:

- Frontend: [report a vulnerability](https://github.com/Kubu-Ventures/pipe-line_gpt-frontend/security/advisories/new)
- Backend and deployment bundle: [report a vulnerability](https://github.com/Kubu-Ventures/pipe-line_gpt-backend/security/advisories/new)

The full policy (response times, scope, supported versions and the operator hardening checklist) is in the [backend repository's SECURITY.md](https://github.com/Kubu-Ventures/pipe-line_gpt-backend/blob/main/SECURITY.md).
